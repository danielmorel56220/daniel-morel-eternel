PARTIE 1 — CADRE PÉDAGOGIQUE
==========================================================================

=== STRUCTURE DES FORMATIONS ===

FORMATION BASES ENNÉAGRAMME — 21 heures (3 jours)
Organisme : Résonance Formation puis Daniel Morel Institut
Ratio : 20% théorie / 80% expérimentation
Public : Managers, coachs, cadres, chefs de projet, professionnels de la relation d'aide, enseignants, formateurs, éducateurs
Outils complémentaires intégrés : PNL, Analyse Transactionnelle, CNV, Communication Éricksonienne, méthode ESPERE

Structure journalière :
- Jour 1 matin : Communiquer — adapter son comportement à son interlocuteur / faciliter la relation de confiance / différencier comportement et motivation
- Jour 1 après-midi : Identifier les motivations profondes de son interlocuteur / questionner avec des outils spécialisés
- Jour 2 matin : Prévoir — identifier le comportement-refuge en situation de stress / utiliser ses ressources sous pression
- Jour 2 après-midi : Identifier sa perception du temps et celle des autres / construire un projet de progression
- Jour 3 matin : Manager — utiliser l'Ennéagramme en relations humaines d'entreprise / mettre en valeur les compétences de chacun
- Jour 3 après-midi : Reconnaître les différents styles de travail / motiver chacun pour développer la performance de l'équipe
Un livret pédagogique est remis à chaque participant.

FORMATION APPROFONDISSEMENT ENNÉAGRAMME — 21 heures (3 jours)
Objectifs spécifiques :
- Instaurer une relation de collaboration rapidement
- Transformer une situation de stress en apprentissage
- Coacher son équipe
- Améliorer la gestion du temps
- Manager par la considération
- Coacher les différents styles de travail
Contenu spécifique approfondissement :
- Les centres mental/émotionnel/instinctif comme piste de management
- Mécanismes de défense et d'apprentissage
- Management personnalisé
- Définition de missions personnalisées pour chaque membre de l'équipe
- Constellations Ennéagramme (exercice des parties)

FORMATION EGO / FORCE DE L'EGO — 2,5 jours
Pas de prérequis / pas de limite de participants
Usage conférence/entreprise/CJD/associations

PARTIE 2 — FONDEMENTS THÉORIQUES : LE MODÈLE EGO / ESSENCE
==========================================================================

=== LES BESOINS FONDAMENTAUX ET LA GENÈSE DE L'EGO ===

CONCEPT : LES 3 BESOINS FONDAMENTAUX DU BÉBÉ
Tout repose sur trois besoins fondamentaux du nourrisson, dont la satisfaction dépend à 100% de l'environnement :
- AMOUR
- SÉCURITÉ
- RECONNAISSANCE
Le bébé est 100% dépendant de son environnement. Daniel Morel appelle les figures d'autorité qui "président" à sa vie : les PRÉSIDENTS.

CONCEPT : LA LOI DU CONDITIONNEMENT OPÉRANT (B.F. Skinner)
"Un individu apprend à associer un comportement spécifique à un stimulus positif ou négatif, ce qui influence la probabilité que le comportement se reproduise ou se réduise à l'avenir."
Métaphore centrale : La superstition du pigeon — le pigeon développe des comportements superstitieux (battre des ailes, ne pas bouger la patte) en croyant qu'ils causent la distribution de graines. L'enfant fait de même pour obtenir amour/sécurité/reconnaissance.
Formulation Daniel Morel : "L'EGO ou LA SUPERSTITION DU PIGEON."

CONCEPT : LE JARDIN D'ÉDEN vs LE VIDE
- Jardin d'Éden = état de plénitude prénatal, tout était là, pas de manque
- Vide = détresse infantile, souvenir inconscient du manque
- L'angoisse est le signal que l'on se rapproche du vide
- L'enfant ne cherche pas à fuir le vide, il cherche à le REMPLIR
- La cellule de crise décide alors d'un PERSONNAGE pour combler ce vide

CONCEPT : LA GÉNÉRALISATION DE L'EGO
L'enfant généralise progressivement : maman → les femmes → les gens → l'environnement en général. Il finit par "diviniser/déifier l'environnement", devenant un serviteur de son environnement au lieu d'être l'acteur de sa vie.

CONCEPT : LES 3 STRATÉGIES DE L'EGO POUR COMBLER LE VIDE
1. Devenir quelqu'un (identité/personnage → les 9 types Ennéagramme)
2. Faire quelque chose (comportements à avoir et à ne pas avoir)
3. Posséder quelque chose (les MON-MAMES)

CONCEPT : LES MON-MAMES (extensions du personnage EGO)
Ce que l'on possède pour combler le vide et obtenir de l'environnement :
- Hitech (dernier iPhone, Tesla)
- Argent
- Corps (forme physique, apparence)
- Études (Bac+5, l'université)
- Fonction (titre, poste)
- Enfants réussis
- Biens matériels divers
Question discriminante : "Est-ce que j'ai besoin que ça se voit ? que ça se sache ?" Si oui → dynamique EGO.
Exemple Daniel Morel : "Ah mais si j'ai une Ferrari, il faut la garer près de l'entrée."

CONCEPT : L'AMBITION DE L'EGO (3 niveaux)
Se regarder avec les yeux des autres / Avoir raison / Contrôler
- AVOIR + : Mon/Ma/Mes, Hitech, Argent, Corps, Études, Fonction, Enfants
- ÊTRE + : Différent, Distinct, Fort, Fiable, Parfait, Approuvé, Décalé, Le meilleur
- FAIRE + : Plaisir, Aimer tout le monde, Réussir, Gagner, Se débrouiller, Tout savoir
- Sinon je suis : nul, stupide, incapable → Angoisse

CONCEPT : LES 5 NIVEAUX DE PERCEPTION DE SOI
1. Tel que je suis : Parfait
2. Tel que je me perçois : Imparfait
3. Tel que je crois qu'il faut me corriger pour être : Parfait
4. Tel que je crois que les autres me perçoivent : Parfait
5. Tel que les autres me perçoivent réellement : Caricature

=== LE TABLEAU DE CONTRASTE EGO / ESSENCE ===

| EGO / JE / Personnalité | MOI / ESSENCE / Identité |
|---|---|
| 100% dépendance | 100% autonomie |
| Extérieur | Intérieur |
| Exister | Vivre |
| Évitement | Réalisation |
| Angoisse / Souffrance | Amour / Sens |
| Reconnaissance / Considération / Sécurité | Satisfaction / Estime de soi / Confiance en soi |
| Fier / Aimé / En paix (recherché à l'extérieur) | Liberté / Plénitude (vécu de l'intérieur) |
| Je suis l'objet du projet des autres | Je suis l'acteur de ma vie |
| Vie = vide | Vie = liberté |

CONCEPT : BASCULE DU JE VERS LE MOI
- JE = objet du projet des autres → EXISTER
- MOI = acteur de ma vie → VIVRE
- Mode EGO : Je est au service des Présidents / change de Président mais reste serviteur
- Mode ESSENCE : Je devient Président de sa vie / acteur de sa vie

CONCEPT : L'AMBITION DE L'ESSENCE
- Je fais ce qui fait sens pour moi
- Je possède ce qui fait sens
- J'accepte de ne pas toujours être compris
- Je suis unique et tellement humain
- Je suis relié de manière subtile
- Je fais confiance
- Je m'ouvre aux visions des autres

CONCEPT : LA SOLUTION D'HIER EST LE PROBLÈME D'AUJOURD'HUI
"Notre EGO a été une solution géniale hier parce que nous étions dépendants. Aujourd'hui nous restons dépendants parce que c'est toujours lui qui préside à nos vies."

=== LES RÈGLES DE L'ESSENCE ===
(Règles fondamentales de la relation vraie et du MOI)
1. Pas de jugement
2. Pas d'interprétation
3. Pas de solution
4. Pas de polarité
5. Pas de prise en charge

=== LES BESOINS DE RÉALISATION ===
Pyramide de réalisation (non-Maslow, version Daniel Morel) :
- PLAISIR / RÉALISATION / AUTONOMIE / SENS
- Physique / Matériel / Financier / Relationnel / Reconnaissance / Comprendre / Expliquer / Info / Écologie / Sens / Spirituel
- Si non satisfaits : FRUSTRATION / DESTRUCTION / DÉPENDANCE / NON SENS
"Pas de mauvaises personnes… que des personnes à la mauvaise place."
"L'intérêt donne l'énergie de sortir de la zone de confort." (25 à 30 jours pour ancrer un nouveau comportement)

PARTIE 3 — LES 9 TYPES : DESCRIPTION COMPLÈTE
==========================================================================

Principe fondateur commun à tous les types :
Chaque type est une STRATÉGIE DE SURVIE développée par la cellule de crise inconsciente pour obtenir amour, sécurité et reconnaissance, en s'éloignant du vide et de la détresse infantile. Ce n'est pas qui l'on est, c'est le costume/personnage que l'inconscient a choisi.
"L'Ennéagramme ne vous dira jamais qui vous êtes — il vous montrera comment vous vous êtes organisés pour survivre face au vide."
"Il faut être fou pour confier son discernement à un Expert [= sa stratégie de survie]."

--- TYPE 1 — L'EGO DU PARFAIT ---
Noms : Le Parfait, Le Perfectionniste, "Monsieur Propre de la morale"

Angoisse fondamentale : Ne pas être à la hauteur, être pris en défaut, être jugé comme fautif

ÊTRE + : Parfait (ne pas être à la hauteur)
FAIRE + : Parfaitement
Comportements à AVOIR : Être correct, rigoureux, irréprochable, se pousser à corriger, progresser sans cesse
Comportements à FUIR : Être négligeant, approximatif, relâché
Double peine : Cherche à être parfait ET à faire parfaitement.

Intelligence développée : Voit les défauts, corrige pour progresser, aspire à de hautes valeurs, s'oblige à l'excellence
Métaphore : Lorsqu'il entre dans une pièce, il voit immédiatement ce qui ne va pas. Un juge intérieur veille en permanence.
Caricature : "Le donneur de leçons" — fiable, ordonné, dévoué mais ennuyeux et moralisateur. Colère peu consciente qui peut exploser. Exigeant avec lui-même, très exigeant avec les autres.

Avec aile 2 : Plus ouvert et aimant, mais encore plus dans l'abnégation (donne, s'épuise, explose)
Avec aile 9 : Plus de tact, accepte mieux les imperfections, mais encore plus dans l'auto-contrôle, butté et renfermé

Ce qu'il y a à apprendre : Il n'est pas bon d'être trop exigeant avec soi-même. Il n'y a pas de mal à faire des erreurs.

Peur (source externe) : Peur d'avoir quelque chose à se reprocher
Compulsion : Refuser les imperfections
Motivation positive : Être fiable et honnête
Blessure & reproduction : On fait des reproches aux autres

Intégrations / Désintégrations :
- Alpha vers 7 (intégration) : accepte d'être imparfait, se libère, profite mieux de la vie
- Mu vers 4 (intégration) : accepte d'avoir un point de vue non universel, embrasse son originalité
- Alpha vers 4 (désintégration) : peur d'être insignifiant, devient égocentré
- Mu vers 7 (désintégration) : peur des émotions négatives, devient insatiable, cumule rigueur et distractions

--- TYPE 2 — L'EGO DE L'INDISPENSABLE ---
Noms : L'Indispensable, L'Aidant, Le Soigneur, L'Altruiste, "La Mère Juive"

Angoisse fondamentale : Être inutile, transparent, remplaçable, ne servir à rien — risque de perdre l'amour/sécurité/reconnaissance

ÊTRE + : Aimant, Aidant (peur d'être rejeté)
FAIRE + : Plaisir, aider, aimer tout le monde
Comportements à AVOIR : Aider, soutenir, anticiper les besoins des autres, deviner que l'autre a froid avant même qu'il le sache, se rendre présent/disponible/attentif/à l'écoute, se positionner où l'autre a besoin de lui
Comportements à FUIR : Être centré sur soi-même, ne pas répondre à une demande, laisser tomber l'autre

Intelligence développée : Relation, empathie, aide, amour des autres, soutien, solidarité, bienveillance
Caricature : "La mère juive" — aimant et généreux, mais étouffant et intrusif. Cherche inconsciemment à être indispensable. Espère de la reconnaissance en retour.

Avec aile 1 : Attend moins de reconnaissance, fait les choses pour "être quelqu'un de bien", veut perfectionner l'autre
Avec aile 3 : Moins centré sur les besoins des autres, obtient plus facilement la reconnaissance, mais manipule l'entourage

Ce qu'il y a à apprendre : Il n'est pas bon de faire passer les besoins des autres avant les siens. Il n'y a pas de mal à prendre soin de soi et demander de l'aide.

Peur : Être perçu comme inutile
Compulsion : Ignorer ses besoins (y compris les motivations de son altruisme)
Motivation positive : Être aimant et altruiste
Blessure & reproduction : Rend les autres inutiles en niant ses propres besoins

Intégrations / Désintégrations :
- Alpha vers 4 (intégration) : accepte de s'occuper de ses propres besoins, découvre son unicité, attend moins de l'extérieur
- Mu vers 8 (intégration) : accepte de lutter pour lui-même, rapport aux autres plus équilibré
- Alpha vers 8 (désintégration) : peur de la faiblesse, devient autoritaire, brutal, rancunier
- Mu vers 4 (désintégration) : peur d'être insignifiant, image de martyr

--- TYPE 3 — L'EGO DU MEILLEUR ---
Noms : Le Meilleur, Le Réussisseur, Le Performeur, "Le Golden Boy", "Le Politicien bling bling"

Angoisse fondamentale : Être un échec, ne pas réussir

ÊTRE + : Le meilleur (peur d'échouer)
FAIRE + : Réussir
Comportements à AVOIR : Avancer, produire, réussir, optimiser son image, travailler dur, viser haut, soigner son apparence, construire la plus belle vitrine (belle voiture, belle maison, beau corps, beau parcours)
Comportements à FUIR : L'échec, la lenteur, la médiocrité

Intelligence développée : Adaptation pour créer les solutions qui assurent le succès des projets
Caricature : "Le politicien bling bling" — hyper adaptable et charmant, réussit tout ce qu'il entreprend, mais prêt à tout pour être admiré (ment et triche facilement). Adore les défis qu'il peut gagner et montrer ses réussites.

Avec aile 2 : Aime partager les fruits de son succès, mais intrusif et manipulateur pour obtenir reconnaissance + admiration
Avec aile 4 : Plus innovant et connecté à ses véritables désirs, mais cherche encore plus à se démarquer

Ce qu'il y a à apprendre : Il n'est pas bon de trop chercher à être vu comme un gagnant. Il n'y a pas de mal à admettre ses défaites et se contenter de ce qu'on a.

Peur : Être perçu comme un perdant
Compulsion : Chercher à être perçu comme meilleur que les autres
Motivation positive : Réussir, s'adapter
Blessure & reproduction : Dévalorise les autres pour se valoriser

Intégrations / Désintégrations :
- Alpha vers 6 (intégration) : accepte de ne pas se démarquer, devient collaboratif plutôt que compétitif
- Mu vers 9 (intégration) : accepte de ne pas être meilleur, gagne en humilité, gagne avec les autres
- Alpha vers 9 (désintégration) : peur du conflit, s'éloigne encore plus de lui-même, défis de narcotisation
- Mu vers 6 (désintégration) : peur d'être rejeté, rabaisser ceux qui ne partagent pas ses valeurs

--- TYPE 4 — L'EGO DU DIFFÉRENT ---
Noms : Le Différent, Le Romantique, L'Artiste, "L'Artiste incompris"

Angoisse fondamentale : Être ordinaire, fondu dans la masse, disparaître, être comme tout le monde

ÊTRE + : Différent (peur d'être comme les autres)
FAIRE + : Différemment
Comportements à AVOIR : Cultiver sa différence, intensifier ses émotions, chercher l'authenticité absolue, ressentir plus fort que tout le monde (une feuille qui tombe devient un poème, une rupture devient une tragédie sublime)
Comportements à FUIR : La banalité, la normalité, la simplicité

Intelligence développée : Intelligence émotionnelle, perçoit au travers du ressenti, capable de créer des réalisations suscitant un ressenti authentique
Caricature : "L'artiste maudit" — original et connecté à ses émotions, mais trop centré sur son image, en conflit avec la norme, versatile (émotions exagérées et changeantes).

Avec aile 3 : Plus pragmatique et ouvert à la norme, mais plus élitiste et moins authentique
Avec aile 5 : Plus rationnel et moins versatile, mais plus de distance avec les autres

Ce qu'il y a à apprendre : Il n'est pas bon de placer l'originalité avant l'authenticité. Il n'y a pas de mal à "être comme tout le monde" ou "suivre le troupeau".

Peur : Être insignifiant (banal, fade ou superficiel)
Compulsion : Rejeter la banalité
Motivation positive : Créer, innover et s'exprimer
Blessure & reproduction : Banalise les autres pour se démarquer

--- TYPE 5 — L'EGO DU SAVANT ---
Noms : Le Savant, L'Expert, L'Observateur, "L'Observateur dans sa tour d'ivoire"

Angoisse fondamentale : Être envahi par les autres ou par ses émotions; ne pas savoir/comprendre

ÊTRE + : Savant (peur d'être envahi)
FAIRE + : Réfléchir, savoir
Comportements à AVOIR : Accumuler des connaissances, analyser, comprendre le monde pour en être distant, penser plutôt que ressentir, observer plutôt que participer
Comportements à FUIR : L'intrusion, la dépendance, l'exposition émotionnelle excessive, les demandes, la proximité, le bruit extérieur
Équation intérieure : Si je reste autonome, discret, autosuffisant → j'obtiendrai amour, sécurité, reconnaissance

Intelligence développée : Intelligence observationnelle, analyse sur le très long terme, quête de sens, art de la solitude
Caricature : "Le savant autiste" — se confond avec sa bibliothèque, observe et analyse finement, mais rationalise tout pour ne pas être envahi émotionnellement. Évite les contacts, se sent vite épuisé par les autres.

Avec aile 4 : Plus conscient de ses propres émotions, mais se coupe encore plus des autres, valorise sa différence
Avec aile 6 : Se connecte à son anxiété, donne une place aux autres, mais rationalise encore plus et devient dogmatique

Ce qu'il y a à apprendre : Il n'est pas bon de trop rationaliser. Il n'y a pas de mal à écouter ses émotions.

Peur : Peur de ses émotions, d'être impacté par son environnement
Compulsion : Rationaliser ses émotions
Motivation positive : Devenir un expert
Blessure & reproduction : Rend difficile la gestion des émotions chez ceux avec qui on relationne

--- TYPE 6 — L'EGO DU DÉVOUÉ / LOYAL ---
Noms : Le Dévoué, Le Loyal, Le Soutien, Le Loyaliste, Le Prévoyant, "Le Scanner à dangers"

Angoisse fondamentale : Se retrouver face au danger seul, sans appui fiable; être trahi, abandonné, exposé sans protection; être surpris/pris au dépourvu

ÊTRE + : Prévoyant (peur d'être surpris, pris au dépourvu)
FAIRE + : Prévoir, faire ce qu'on dit
Comportements à AVOIR : Rester en alerte permanente, repérer les dangers, imaginer tous les scénarios possibles ("et si il pleut", "et si on a un accident", "et si on nous ment"), chercher une autorité fiable, douter, tester en permanence, apparaître comme fiable
Comportements à FUIR : L'insouciance, la naïveté, le lâcher-prise total
Métaphore : Comme un suricate qui scanne l'environnement en permanence
Position contre-phobique : Spécificité du 6 — parfois gère la peur en fonçant vers ce dont il a peur

Intelligence développée : Intelligence de la vigilance et de l'anticipation, règles et organisation pour rendre le monde plus sécure
Caricature : "Le trouillard conformiste" — s'accroche à des croyances et traditions, pilier de la cohésion sociale. Anxieux, inhibé, routinier, très famille. Exclut définitivement quelqu'un s'il le perçoit trop déviant.

Avec aile 5 : Plus rationnel, mais encore plus coupé de ses émotions et plus fuyant
Avec aile 7 : Plus joyeux et aventureux, mais moins responsable et moins ancré dans ses émotions

Ce qu'il y a à apprendre : Il n'est pas bon de trop se conformer. Il n'y a pas de mal à être marginal.

Peur : Être perdu, sans repères ou sans soutien
Compulsion : Rejeter la déviance
Motivation positive : Être loyal à des référents (personnes et culture personnelle)
Blessure & reproduction : Rejette les non conformes pour être conforme

--- TYPE 7 — L'EGO DU FUN ---
Noms : Le Fun, L'Optimiste, L'Épicurien, "Le G.O. du Club Med"

Angoisse fondamentale : L'ennui, la douleur interne, la tristesse, le vide

ÊTRE + : Fun (peur de l'ennui)
FAIRE + : S'amuser, jouir
Comportements à AVOIR : Rester enthousiaste, multiplier les projets, entretenir l'énergie du mouvement, pirouettes, blagues, proposer toujours une nouvelle idée, emmener tout le monde ailleurs
Comportements à FUIR : Les tristesses, la profondeur lourde, l'ennui, tout ce qui rappelle les aspects négatifs de la vie

Intelligence développée : Intelligence de la vision positive, de la créativité et des options multiples, remet du mouvement et de la légèreté là où cela semble bloqué
Caricature : "Le clown de service" — met l'ambiance, amuse la galerie, mais du mal à tenir des engagements. Charmant, drôle, pétillant, inspirant — disparaît dans un nuage de fumée dès que les conversations profondes apparaissent.

Avec aile 6 : Plus responsable et coopératif, mais plus anxieux et moins joyeux
Avec aile 8 : Fuit moins les émotions négatives, mais plus excessif et individualiste

Ce qu'il y a à apprendre : Il n'est pas bon de fuir les responsabilités et la routine. Il n'y a pas de mal à vivre des émotions négatives.

Peur : Peur des émotions négatives
Compulsion : Ne rien faire des émotions désagréables
Motivation positive : Transmettre la joie et la stimulation
Blessure & reproduction : Oblige les autres à gérer plus d'émotions négatives en ne gérant pas les siennes

--- TYPE 8 — L'EGO DU FORT ---
Noms : Le Fort, Le Leader, Le Parrain, Le Dictateur, "Le Parrain"

Angoisse fondamentale : Être faible, vulnérable, dépendant; avoir subi une humiliation due à une faiblesse dans l'enfance

ÊTRE + : Fort (peur d'être faible)
FAIRE + : Se battre, s'imposer
Comportements à AVOIR : Être fort, occuper l'espace, s'imposer, être frontal, direct, respectueux de la puissance, tester les autres sur leur solidité
Comportements à FUIR : La faiblesse, la plainte, la dépendance affective, l'écoute passive, être affecté
Dynamique particulière : Protège son clan. "Son cœur est immense, enfermé dans un coffre-fort gardé par un pit-bull." "Manger ou être mangé."

Intelligence développée : Intelligence de la force vitale, de la protection et de l'affirmation, intelligence de l'action pour trancher et faire avancer
Caricature : "Le dictateur" — fort et brave mais impose sa loi par la force. Divise le monde en alliés et ennemis. Excessif, charismatique, ne réfléchit pas assez avant d'agir. Peut se contredire sans ciller.

Avec aile 7 : Moins dans la lutte, plus dans le plaisir partagé, mais égoïste
Avec aile 9 : Considère la colère comme une faiblesse, plus de tact, prend mieux l'autre en compte, mais perd sa capacité à utiliser l'émotion comme une force

Ce qu'il y a à apprendre : Il n'est pas bon de nier ses faiblesses. Il n'y a pas de mal à panser ses blessures et admettre qu'on a mal.

Peur : Peur d'être faible
Compulsion : Ignorer la faiblesse
Motivation positive : Savoir se battre et résister aux difficultés
Blessure & reproduction : Affaiblit l'autre en l'attaquant pour ne pas être attaqué

--- TYPE 9 — L'EGO DU DIPLOMATE ---
Noms : Le Diplomate, Le Médiateur, Le Pacificateur, L'Endormi, "La Bonne Pâte"

Angoisse fondamentale : Le conflit, les tensions qui menacent ses "cacahuètes"

ÊTRE + : Diplomate (peur du conflit)
FAIRE + : S'accorder, harmoniser
Comportements à AVOIR : S'adapter, dire oui, lisser les tensions, arrondir les angles, fusionner avec les désirs des autres, répondre "c'est comme tu veux"
Comportements à FUIR : Décider, déranger, s'imposer, dire clairement non

Intelligence développée : Intelligence de l'harmonie, de l'unification en évitant les conflits, sait apaiser les tensions, relier les personnes
Caricature : "La bonne pâte" — doux, gentil, tranquille, mais "mouton" qui suit, sans avis clair ni positionnement. Finit souvent par s'oublier. Facilement transparent et invisible. Du mal à prendre des décisions.

Avec aile 1 : Arrive à déterminer ses valeurs et se positionner, plus actif, mais moins ouvert aux opinions différentes
Avec aile 8 : Plus centré sur l'action et ses propres priorités, mais moins pacifique, plus enclin aux actes passifs-agressifs

Ce qu'il y a à apprendre : Il n'est pas bon de trop fuir le conflit. Il n'y a pas de mal à exprimer sa colère et ses divergences d'opinions.

Peur : Peur du conflit, de ne pas être paisible
Compulsion : Ignorer les conflits
Motivation positive : Être pacifique, facilitant, soutenant
Blessure & reproduction : Amplifie les conflits en ne les gérant pas

PARTIE 5 — CONCEPTS THÉORIQUES AVANCÉS

=== LES 3 CENTRES ===

CENTRE 981 — INSTINCTIF / "de la volonté"
Types : 8, 9, 1
- Auto-contrôle / contrôle de soi / volonté
- Peur de ne pas être forts, tranquilles ou irréprochables
- Comptent sur eux-mêmes, cherchent à n'avoir besoin de personne
- Émotion prédominante : la COLÈRE (force du 8 / déni du 9 / problème récurrent du 1)
- C'est l'image qu'on a de soi-même qui compte (basée sur sa propre évaluation)
- Recherche d'intégrité, tendance à nier une part de la réalité

CENTRE 234 — ÉMOTIONNEL / "de la relation"
Types : 2, 3, 4
- Identité / contrôle de son image / valorisation
- Peur de ne pas être reconnus pour leur altruisme, réussite ou unicité
- Comptent sur les autres, cherchent à exister pour les autres
- Recherche d'une image valorisante (au-dessus des autres) : le 2 aide, le 3 réussit, le 4 est moins insipide
- Le déni concerne surtout l'identité : on nie des choses chez soi pour se sentir spécial

CENTRE 567 — MENTAL / "intellectuel"
Types : 5, 6, 7
- Anxiété / contrôle de ses émotions / rationalisation
- Peur de souffrir par manque de distance, de soutien ou de stimulation
- Comptent sur un médiateur entre soi et le monde
- La peur des émotions dirige ce centre : le 5 a peur d'avoir des émotions / le 6 d'être envahi par l'anxiété / le 7 de vivre des émotions négatives
- Le déni est focalisé sur l'impact des émotions

=== L'ORIENTATION INTÉRIEURE/EXTÉRIEURE DES CENTRES ===
- Le 1 cherche à se contrôler intérieurement (son être)
- Le 8 cherche à se contrôler extérieurement (ses actions)
- Le 9 cherche à se contrôler pleinement (être ET actions)
- Le 2 contrôle son image extérieurement (ce que les autres pensent)
- Le 4 contrôle son image intérieurement (ce qu'il pense de lui)
- Le 3 contrôle son image pleinement (lui ET les autres)
- Le 5 contrôle son vécu extérieurement (limite l'impact de l'environnement)
- Le 7 contrôle son vécu intérieurement (voir le positif et imaginer le plaisir)
- Le 6 contrôle pleinement son environnement (limite les risques ET imagine la sécurité)

=== LES AILES ===
- Ennéatype secondaire adjacent à la base qui nuance les expressions de la base
- On peut avoir zéro, une ou deux ailes
- Les ailes sont subordonnées à la base (leur peur est moins forte)
- La compulsion de l'aile sert la compulsion de la base
- Complexifient la personnalité, ajoutent des stratégies d'adaptation
- Notation ex. : "5w4/6" = base 5, aile principale 4, aile secondaire 6

=== LES FLÈCHES (DIRECTIONS D'INTÉGRATION ET DÉSINTÉGRATION) ===
- Les flèches partent de la base ET des ailes
- S'expriment quand le niveau d'intégration ou de désintégration interne est très fort
- Intégration externe : adopter la motivation sans la compulsion d'un ennéatype désigné par une flèche
- Désintégration externe : adopter la compulsion sans la motivation d'un ennéatype désigné par une flèche
Sens Alpha : 9→3→6 et 1→7→5→8→2→4
Sens Mu (minoritaire) : 9→6→3 et 4→2→8→5→7→1

=== LE TRIANGLE DE LA STABILITÉ ===
Types 9, 3, 6 forment un triangle indépendant (leurs flèches ne sortent pas du triangle)
- Plus attachés à la stabilité culturelle, préfèrent le statu quo aux innovations
- Le 9 pour maintenir l'harmonie / le 6 pour protéger son cadre de référence / le 3 pour que sa réussite soit reconnue par la majorité

=== LES SOUS-TYPES (VARIANTES INSTINCTUELLES) ===
- Survie : éléments de confort personnel
- Tête à tête : relation à deux / sexuel : séduction
- Social : groupe d'appartenance
- Sociétal : société, civilisation
(Classiquement regroupés : sexuel + tête à tête / social + sociétal)

=== NIVEAUX DE DÉVELOPPEMENT / INTÉGRATION ===
- Plus on va mal → plus on exprime les compulsions négatives
- Plus on va bien → plus on s'en libère pour exprimer les motivations positives
- Un profil se définit par une combinaison complexe : base + ailes + sous-types + sens d'intégration — pas par un chiffre seul

=== EXERCICE 1 : LES CONSTELLATIONS ENNÉAGRAMME (Système de Parties) ===

Niveau : Approfondissement (2e et 3e jour)
Durée : 45 à 90 minutes par personne
Modalité : Groupe + facilitateur + représentants (personnes ou tasses)

PRINCIPE :
Chaque base Ennéagramme représente une énergie/partie de la personne. Sa configuration complète inclut sa base principale et ses bases reliées (ailes + flèches d'intégration/désintégration). Travailler sur les parties internes via une mise en espace symbolique (constellation).

"La problématique récurrente ne peut exister que grâce à la configuration. Changer la configuration et les choses évoluent d'elles-mêmes."
"Arrêtons de vouloir régler les problèmes à l'extérieur, puisqu'il suffit de les régler à l'intérieur."

PROTOCOLE (7 étapes) :

Étape 1 — Identification de la situation récurrente
- Le participant se connecte à une situation récurrente ("un problème, en tout cas une situation qui est toujours là, qui est toujours présente énergétiquement")
- Il peut l'évoquer factuellement ou garder ça secret
- Consigne stricte : "décris les faits, pas ce que tu vis à l'intérieur, pas ce que ça te fait"
- Exemple : situation professionnelle qui revient, relation qui accroche, comportement qu'on n'arrive pas à changer

Étape 2 — Choix de la symbolique
- Choix entre représenter ses parties avec des PERSONNES de la salle ou avec des TASSES (objets)
- "La symbolique est un des langages les plus puissants"
- Si personnes : elles vont s'exprimer / Si tasses : elles symbolisent sans s'exprimer
- Aucun choix n'est meilleur que l'autre — c'est ce qui résonne pour le participant

Étape 3 — Mise en place de la configuration dans l'espace
- Le participant choisit des personnes (ou des tasses) pour représenter chacune de ses bases Ennéagramme
- Sa configuration inclut sa base principale ET ses bases d'intégration/désintégration
- Exemple pour une base 7 : parties présentes = 7, 1, 5, 2, 8, 6 (la base + les flèches + les ailes)
- Il place chaque personne/symbole dans l'espace de la pièce à l'endroit qui lui semble juste
- Il se place lui-même au centre de sa configuration
- Consigne du facilitateur : "Il n'y a pas de logique. La logique, elle est la tienne." / "Je cherche avec mon corps plutôt."

Étape 4 — Observation de la configuration sous différents angles
- Le participant se promène dans l'espace, observe sa configuration sous différents angles
- Questions du facilitateur : "comment tu te sens à cet endroit ?" / "qu'est-ce que tu remarques ?"

Étape 5 — Recueil des ressentis de chaque partie
- Le facilitateur interroge chaque représentant : "Quand tu vois que [nom] est dans cette situation, comment tu le/la sens ? Quel est ton ressenti ?"
- Consigne stricte : "pas l'intellect, le ressenti" / "dans quel état émotionnel ça te met ?"
- Référentiels émotionnels proposés : "dans le monde de la peur, de la tristesse, de la colère, du dégoût ?" / "agréable, désagréable ?"

Étape 6 — Modification de la configuration
- Le participant décide de modifier les positions des parties
- "Tu as envie de bouger quoi ? Comment tu as envie de faire évoluer cette configuration ?"
- Chaque ajustement est testé, ressenti, évalué
- "Un essai. Tu peux changer à tout moment. Tu peux garder ou t'éloigner."

Étape 7 — Débrief et ancrage
- "Comment c'est pour toi, là ?"
- On donne des labels aux forces : "la force de jouir, la force de la compréhension, la manière de s'imposer, la prudence et l'anticipation, quelque chose de juste et d'éthique"
- Ancrage cybernétique : "quand on bouge quelque chose dans le monde du dedans, ça a un impact sur le monde du dehors"

Principes du facilitateur pendant l'exercice :
- "Aucune solution, jamais" — "Mes clés de voiture n'ouvrent pas la tienne"
- "Les conseils ne valent que pour ceux qui les donnent"
- "L'expérience des uns est un peigne pour les chauves"
- "Aucun exercice n'est ni commencé ni terminé, on explore"
- Pas de réponse bonne ou mauvaise

VARIANTE — LES TASSES (terrasse de café) :
Au lieu de personnes, on pose des tasses sur une table. Le participant réajuste les tasses en fonction de sa proximité souhaitée avec chaque énergie. Exercice dit "des tasses à la terrasse d'un café."

=== EXERCICE 2 : LA ROUE DE L'ENNÉAGRAMME ===

Niveau : Approfondissement
Durée : 20 à 30 minutes (réflexion + partage)
Modalité : Individuel puis groupe

PRINCIPE :
Voir les 9 types Ennéagramme comme une roue dont les bases sont les rayons. Si une base est sur-développée, la roue est ovale/déséquilibrée.
"À haute vitesse, ça casse tout." — Illustration : pneu ovalisant sur un camion → vibration à vitesse élevée.
"On est obligé de vivre de petites choses si on veut que ça marche avec une roue ovale. Dès que tu veux vivre de grandes choses, ça casse."

PROTOCOLE :
1. Identifier sa base principale et les bases les plus développées dans sa configuration
2. Tracer sa roue intérieure (radars des 9 bases — force de 1 à 10 pour chaque base)
3. Observer : quelle base est sur-développée ? Laquelle est sous-développée ?
4. Question de réflexion : "Quand tu investis massivement dans [base 2] et que tu reçois peu, qu'est-ce que ça génère ?" → frustration, colère, épuisement
5. Question pivot : "Quelle base devrait être plus développée pour que la roue soit équilibrée ?"

=== EXERCICE 3 : L'ÉTALONNAGE PERSONNEL (Concept des "Donuts") ===

Niveau : Approfondissement (2e jour)
Durée : 30 à 45 minutes
Modalité : Réflexion individuelle + partage groupe

PRINCIPE :
S'étalonner = vivre des expériences variées pour créer des polarités plus larges. La vie intérieure est comme un donut dont l'espace intérieur peut être grand ou petit.

Citations clés :
- "Vivre, c'est s'étalonner. On crée au départ de sa vie l'espace dans lequel on va vivre."
- "Celui qui a fait 30 ans la même journée n'a pas 30 ans d'expérience, il a une journée d'expérience."
- "Plus l'espace entre le pôle génial et le pôle catastrophique est grand, plus on a de la vie."
- "La voie de la sagesse ne s'enseigne pas. Elle est le chemin qu'on choisira entre deux polarités que nos excès nous auront fait vivre."

PROTOCOLE :
1. Identifier son "donut" : qu'est-ce qui constitue ma zone de confort / ma zone d'expansion ?
2. Questions : Dans quels domaines ai-je vécu des expériences extrêmes (très bonnes ET très mauvaises) ?
3. Dans quels domaines ai-je un espace étroit (ni très bon, ni très mauvais) ?
4. La contrainte de l'EGO : dans quels domaines mon EGO m'empêche-t-il de m'étalonner ?
5. Pont futur : quelle expérience volontaire pourrait élargir mon donut dans un domaine clé ?

VARIANTE MÉTAPHORE :
"La vaisselle en avance" : on ne peut pas faire la vaisselle en avance pour demain. On ne peut pas prendre de l'avance sur la vie — l'expérience ne précède pas la rencontre.
"La plaquette de beurre" : étalonnage minimal vs vie amplifiée.

=== EXERCICE 4 : LE DÉBRIEFING POST-TEST (6 étapes) ===

Niveau : Bases ET Praticien PNL (après module PNL)

PROTOCOLE :
1. Choisir le bon moment pour faire le test (état émotionnel neutre, période stable)
2. Réflexion et auto-évaluation honnête (éviter l'image idéalisée)
3. Faire le test plusieurs fois (à différents moments, dans différents états d'esprit) → identifier la constante
4. Prendre en compte le contexte actuel de vie (stress, deuil, amour, etc.)
5. Consulter un professionnel pour valider et approfondir
6. Combiner ce test avec d'autres outils (MBTI, PNL, valeurs)

Questions de débrief :
- "Quand tu te lis ce profil, est-ce que tu reconnais quelqu'un que tu as été ?"
- "À quelle époque de ta vie ce profil te ressemble-t-il le plus ?"
- "Y a-t-il des comportements dans ce profil qui t'ont déjà causé des problèmes dans ta vie ?"
- "Et les ressources/intelligences développées — te reconnais-tu dedans ?"

=== UTILISATION DE L'ENNÉAGRAMME EN MANAGEMENT ===

Par type, la question managériale fondamentale est :
- Type 1 : Comment lui permettre d'atteindre l'excellence sans s'épuiser ou moraliser l'équipe ?
- Type 2 : Comment reconnaître sa contribution sans le laisser s'oublier ni créer de dépendance ?
- Type 3 : Comment canaliser son besoin de performance vers les objectifs collectifs ?
- Type 4 : Comment valoriser sa créativité et son unicité sans amplifier la dramaturgie ?
- Type 5 : Comment obtenir sa contribution sans l'envahir ni le surcharger d'interactions ?
- Type 6 : Comment sécuriser son cadre pour libérer son potentiel d'anticipation ?
- Type 7 : Comment maintenir son enthousiasme tout en structurant la tenue des engagements ?
- Type 8 : Comment travailler avec sa force sans créer de rapports de domination ?
- Type 9 : Comment faire émerger son positionnement et ses décisions sans le forcer ?

=== COMPORTEMENT-REFUGE EN SITUATION DE STRESS (par type) ===
(Programme bases — Jour 2 matin)
- Type 1 sous stress : critique encore plus, rigidité accrue, explosions de colère retardées
- Type 2 sous stress : épuisement total par sacrifice, puis resentiment et réclamations
- Type 3 sous stress : mensonge, triche, déni de l'échec, façade de plus en plus coûteuse
- Type 4 sous stress : repli émotionnel, sentiment d'abandon unique, jalousie intense
- Type 5 sous stress : isolation totale, refus de tout contact, coupure des émotions
- Type 6 sous stress : scénarios catastrophe en cascade, paralysie ou contre-phobique
- Type 7 sous stress : fuite en avant, hyperactivité compulsive, décisions irresponsables
- Type 8 sous stress : destruction, attaques frontales, domination explosive
- Type 9 sous stress : narcotisation totale, procrastination extrême, inertie, disparition

=== STYLES DE TRAVAIL PAR TYPE (Jour 3 après-midi) ===
- Type 1 : travail méthodique, perfectionniste, axé sur les procédures et la qualité
- Type 2 : travail centré sur les gens, disponible, besoin de reconnaissance pour s'investir
- Type 3 : travail orienté résultats et image, efficace, besoin d'objectifs mesurables
- Type 4 : travail créatif et expressif, besoin d'autonomie et de sens émotionnel
- Type 5 : travail analytique et en autonomie, besoin de temps et d'espace pour penser
- Type 6 : travail structuré et en équipe fiable, besoin de clarté des rôles
- Type 7 : travail dynamique et varié, besoin de nouveauté et de liberté
- Type 8 : travail énergique et décisionnel, besoin d'être respecté et d'avoir de l'impact
- Type 9 : travail harmonieux et solidaire, besoin de temps pour décider et absence de conflit

=== MOTIVER CHAQUE TYPE (Jour 3 après-midi) ===
- Type 1 : reconnaître son excellence et sa rigueur / lui donner de l'espace pour progresser
- Type 2 : exprimer sincèrement la reconnaissance de sa contribution
- Type 3 : valoriser publiquement ses réussites / fixer des objectifs ambitieux
- Type 4 : valoriser son originalité / lui donner des projets avec du sens émotionnel
- Type 5 : respecter son besoin de distance / lui confier des missions d'expertise
- Type 6 : créer un cadre stable et prévisible / être cohérent entre paroles et actes
- Type 7 : offrir de la variété et des projets stimulants / lui permettre de partager son enthousiasme
- Type 8 : lui donner du pouvoir décisionnel / être direct et respectueux
- Type 9 : l'inclure dans les décisions / lui exprimer que son avis compte

PARTIE 11 — INTÉGRATION AVEC LA PNL
==========================================================================

=== CORRÉLATIONS ENNÉAGRAMME / PNL ===

Le test Ennéagramme est utilisé dans la formation Praticien PNL APRÈS un module PNL pour débriefer les profils et montrer la corrélation entre profils Ennéagramme et patterns PNL travaillés.

CORRÉLATIONS PRINCIPALES :
- Type 1 → Opérateurs modaux de nécessité (devoir, falloir) + référence interne/externe exigeante
- Type 2 → Méta-programme Vers (vers les autres) + Actif / tris primaires Personnes
- Type 3 → Méta-programme Vers (vers la réussite) + Match (voit ce qui va) + Global
- Type 4 → Mismatch (voit les différences) + Sous-modalités émotionnelles intenses
- Type 5 → Through Time + Référence interne + Global (vision d'ensemble analytique)
- Type 6 → Loin (éloignement des dangers) + Mismatch (voit ce qui ne va pas) + Through Time
- Type 7 → Options (vs Procédures) + Match + Futur + Actif
- Type 8 → Actif + Référence interne + Opérateurs modaux de possibilité
- Type 9 → Réceptif + Through Time + Passé/Présent

Les émotions-refuges par centre correspondent aux alertes émotionnelles PNL :
- Centre Instinctif (8/9/1) → Alerte colère
- Centre Émotionnel (2/3/4) → Alerte tristesse/honte/envie
- Centre Mental (5/6/7) → Alerte peur/anxiété
